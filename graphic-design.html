// faq

What file formats do you deliver?

We deliver SVG, PNG (various sizes), print-ready PDF, and editable source files in Figma or Adobe format depending on the project.

Can you match an existing colour palette?

Yes — if you have existing brand colours or guidelines, we design within them. Share what you have when you reach out.

Do you design for print and digital?

Yes — we design for both. Print files are set up at the correct resolution and bleed for professional printing.
